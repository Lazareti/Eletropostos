# Rede de Eletropostos da Região Sul

Projeto desenvolvido para a disciplina de **Teoria dos Grafos**, do curso de Ciência da Computação da Universidade Presbiteriana Mackenzie.

## Sobre o projeto

O trabalho utiliza conceitos de Teoria dos Grafos para analisar a distribuição de eletropostos na Região Sul do Brasil, buscando identificar rotas viáveis para veículos elétricos e regiões com necessidade de novos pontos de recarga.

A aplicação foi desenvolvida em Python e utiliza dados do OpenStreetMap e distâncias rodoviárias obtidas pelo OSRM.

## Objetivos

- Encontrar as menores rotas entre eletropostos, respeitando a autonomia dos veículos.
- Analisar a conectividade da rede de recarga.
- Identificar estações e conexões críticas.
- Estimar a necessidade de novos eletropostos em regiões com pouca cobertura.

## Técnicas utilizadas

- Algoritmo de Dijkstra para cálculo de rotas.
- Graus dos vértices.
- Análise de Euler.
- Coloração de grafos.
- Pontos de articulação e pontes.
- Árvore geradora mínima.
